# admission_record

Future object describing an accepted public admission record.

Allowed public fields may include:

- `rho`
- `N_old`
- `C_new`
- `rt_state`
- `newStateRoot`
- `actionHash`
- `amountCom`
- `clauseCom`

Forbidden fields include:

- `C_old`
- `owner_u`
- `usedAmount_old`
- `usedAmount_new`
- `amount_j`
- `r_amt`
- Merkle paths
- User-level linking tags
